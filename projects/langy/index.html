Langy is a macOS utility that automatically switches keyboard language while people work, reducing interruptions and repeated manual corrections.

OSAM designed the product experience and visual identity, created the website and developed the application in Swift as one focused desktop product.

The challenge: automation users can understand

A useful keyboard language switcher should feel almost invisible, but users still need confidence that it is learning the right behaviour. The product had to automate repetitive actions without becoming difficult to configure or unpredictable.

We organised settings around clear decisions: when automatic switching is active, how languages behave, what shortcuts are available and where users remain in control. Native macOS patterns make the interface familiar from the first launch.

UX/UI designed around uninterrupted work

Langy’s interface keeps the most important status and controls easy to find while moving advanced preferences out of the main workflow. Concise labels, predictable toggles and clear system feedback reduce the effort required to set up the app.

The product design translates directly into Swift components, helping visual behaviour and implementation stay aligned. This connection between design and development keeps the macOS experience responsive, consistent and ready to evolve.

A small utility designed to protect focus and feel native to macOS.

From product interface to launch-ready identity

The visual system gives a technical utility a friendly, recognisable presence across the app and marketing website. Typography, colour and interface imagery explain the benefit without overcomplicating the message.
